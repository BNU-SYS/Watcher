# CWE-369: Divide By Zero

Report when a feasible zero divisor reaches an actual Java operation that fails on zero.

1. Locate integral `/`, `%` or an applicable `BigInteger`/`BigDecimal` operation. Determine operand types and promotions.
2. Trace the divisor's zero-producing input or assignment, including unboxing. Check guards, early exits and reassignment after validation.
3. Confirm that the path reaches the operation before another exception or exit.

Identify the divisor, trigger and failing operation. Locate that operation. Exclude floating-point IEEE 754 behavior, nonterminating decimal expansion and zero dimensions used only in multiplication, allocation or indexing. A divisor proven nonzero refutes the candidate. Record essential missing helper behavior in `limitations`.
