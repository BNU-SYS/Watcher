# CWE-772: Missing Resource Release

Report when the code acquires an external resource, owns its release and has a reachable exit that leaves it open.

1. Identify acquisition, aliases, wrappers and ownership transfer. Check files, sockets, JDBC resources and resource-backed streams such as `Files.lines`.
2. Trace normal, exceptional and partial-initialization exits. A later acquisition or earlier `close()` may throw before remaining cleanup.
3. Check try-with-resources, reliable finally blocks, lifecycle methods and parent/wrapper cleanup contracts.

State the resource, owner and leaking exit. Locate acquisition when no explicit failing release operation exists. Effective ownership transfer or cleanup refutes the path. AutoCloseable declarations and in-memory streams alone establish no external release obligation. Record essential unknown ownership contracts in `limitations`.
