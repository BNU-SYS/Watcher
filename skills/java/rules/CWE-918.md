# CWE-918: Server-Side Request Forgery

Report when controlled input causes server-side retrieval beyond an established destination boundary.

1. Trace URI components, redirects and helpers to actual request execution, such as HttpClient or URLConnection reads.
2. Identify the destination policy and a concrete accepted URI that violates it. Check scheme, host, port, origin parsing and final request destination.
3. Evaluate allowlists and string checks using URI semantics. Assess redirects and DNS behavior through supported client contracts.

Locate the server-side request and give the input, boundary and bypass. Browser redirects, inert URLs, safely bound query data and intentional unrestricted fetching require further evidence of a violated boundary. Record essential unknown policies or network/client behavior in `limitations`; support internal access or disclosure claims separately.
