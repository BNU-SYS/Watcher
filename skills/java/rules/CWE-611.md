# CWE-611: XML External Entity Reference

## Report only when

Supplied XML can cause unauthorized external entity or DTD resolution under a supported parser configuration or API contract.

## Review steps

1. Follow XML text, `InputStream`, `Reader` or `InputSource` to the actual parse/transform call. Establish the local input surface and visible restrictions.
2. Track the factory, reader, resolver and settings used by that call. Check external general entities, parameter entities and external DTD loading separately. Entity flags alone leave `nonvalidating/load-external-dtd` behavior to inspect.
3. Follow configuration after parser-construction branches through to the parse call. Settings applied to the resulting reader protect all branches that reach them. For a supplied `XMLStreamReader`, trace its factory/helper contract and later use. Record unknown helper behavior as a specific evidence gap.
4. Evaluate effective external-access restrictions, including `XMLConstants.ACCESS_EXTERNAL_DTD`, resolver behavior and failed configuration. Establish which mechanisms third-party options such as `setResolveEntities(false)` control.
5. Construct an external-reference trigger, such as an external `DOCTYPE SYSTEM`, and explain the permitted resolution. Record essential unknown defaults at the specific call in `limitations`.

## Evidence and exclusions

Identify the input, parser instance, effective behavior and resolution trigger. Locate parsing or decisive configuration. Support remote reachability and disclosure impact separately. Effective external-reference rejection refutes the path. XML parsing or one absent flag alone is insufficient. Distinguish internal expansion, XInclude and stylesheet retrieval by their actual mechanism.
