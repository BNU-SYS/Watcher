# CWE-787: Out-of-bounds Write

Report a feasible write beyond an established memory region through an operation that bypasses Java bounds checks, such as a supported Unsafe or native operation.

1. Identify the primitive and its checking contract, region extent, base address, offset and write width.
2. Trace units, conversions and arithmetic into a write outside that region.
3. Check guards and rejection paths before the actual write. Require visible native behavior or an applicable unsafe contract.

Locate the unsafe write and state the violated bounds. Ordinary array/buffer exceptions, native declarations, direct-buffer allocation or imports alone supply insufficient evidence. Distinguish reads, invalid allocation, null access and use-after-free. Record missing region or native contracts in `limitations`, and limit impact to the supported write.
