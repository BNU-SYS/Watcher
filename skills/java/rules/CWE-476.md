# CWE-476: Null Pointer Dereference

Report when a supported null-producing path reaches an actual dereference or implicit unboxing.

1. Establish nullability from assignments, branches, visible callers or API contracts such as `Map.get` for an absent key. Trace aliases and return values.
2. Locate instance/array access or unboxing. Check guards on the same value, short-circuiting, early exits, `requireNonNull` and later reassignment.
3. Apply API guarantees. `Object.getClass()` returns a class for a non-null receiver. `TypeVariable.getBounds()` supplies `Object` for an unbounded variable. Unknown helper contracts alone establish no null-producing path.

State the null origin, trigger, dereference and ineffective protection. Locate the dereference. Exclude guarded paths, null-safe operations and unsupported concurrency assumptions. Treat array-index exceptions according to their actual mechanism. Record essential missing contracts in `limitations`.
