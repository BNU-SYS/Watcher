# CWE-434: Upload of File with Dangerous Type

Report when a controlled upload is accepted into a demonstrated type-sensitive storage, serving, execution or processing context without effective restrictions.

1. Trace bytes, name, extension and declared MIME type to the actual destination or consumer.
2. Establish the allowed policy and an accepted file that becomes dangerous there.
3. Check server-side type validation, generated names, storage isolation, serving headers and execution restrictions on the final content.

Identify the dangerous type, consumer, failed restriction and consequence. Locate acceptance, persistence or dispatch. Isolated nonexecutable storage and effective serving restrictions refute the relevant path. Use CWE-22 for the same root cause when only a directory escape is established. Record unknown consumer behavior in `limitations`.
