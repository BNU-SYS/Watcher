### CWE-125: Out-of-bounds Read

- Establish the read object, real capacity, storage class, index or byte count, access direction, feasible out-of-range value, and missing or bypassed validation.
- Include array subscripting, pointer arithmetic followed by a read, `memcpy`/`memmove`-like reads, string reads, and container or buffer access when capacity and read length are clear.
- A global array read such as `static int g_acc_cfg[3]; max_idx = g_acc_cfg[idx1];` is `CWE-125` when `idx1 < 0` or `idx1 >= 3` is reachable. Do not call a global object a stack buffer.
- Do not report a write as `CWE-125`. Do not infer an out-of-range value when a visible caller contract or dominating guard proves the index in range. Check negative indices, off-by-one limits, signed/unsigned conversion, and size arithmetic.
- A visible out-of-range constant, a pointer formed beyond the last element and then read, or an explicit in-file caller supplying an out-of-range value is sufficient proof.

#### Finding location

- The primary operation is the expression or operation that reads beyond the object's bounds. Explain the object's capacity and the out-of-range access.
