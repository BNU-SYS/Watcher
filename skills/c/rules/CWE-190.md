### CWE-190: Integer Overflow or Wraparound

- Trace attainable values through addition, multiplication, shifts, increments, or other arithmetic. Establish operand types, promotions, the value range crossing the representable maximum, and the visible consequence required by this rule.
- A visible operation whose operands are established in the supplied file to cross the maximum is sufficient, even without a later allocation or memory access. For signed arithmetic, describe undefined behavior rather than assuming modulo arithmetic; for unsigned arithmetic, describe fixed-width wraparound.
- Check widening intermediates, pre-operation bounds checks, checked-arithmetic builtins, constants, sanitizing conversions, and compiler rules. Do not report an ordinary expression without a feasible overflow.

#### Finding location

- The primary operation is the source expression that performs arithmetic whose mathematical result exceeds the operation type's representable maximum. Distinguish that original expression from the numeric calculation used to prove overflow: substituted operand values establish the trigger but do not create an arithmetic expression at the caller. Explain the original expression, operand values, operation type, and resulting overflow or wraparound.
