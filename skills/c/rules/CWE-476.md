### CWE-476: NULL Pointer Dereference

- Establish a feasible null source: explicit assignment or branch, failed allocation, visible nullable lookup, or a caller that can supply null. Identify the reachable `*p`, `p->member`, pointer-based array access, call requiring a non-null pointer, or implicit dereference.
- An unchecked `malloc`/`calloc`/`new` result is evidence only when allocation failure is feasible and the pointer is subsequently dereferenced. An unconstrained pointer parameter alone is not proof.
- A null value explicitly created in the file, visible nullable lookup, or visible allocation-failure branch is sufficient; do not require an external caller when the local path reaches the dereference.
- Check guards on the same pointer or preserving alias, early returns/throws, short-circuit evaluation, reassignment, and visible helper validation. A check after the dereference cannot protect it. Comparisons, address-taking, and `sizeof(pointer)` are not dereferences by themselves.

#### Finding location

- The primary operation is the explicit or implicit access through the null pointer. Follow visible helper implementations to the actual access. For a library or external function whose implementation is not supplied, locate the call expression when its established contract requires a valid pointer for the relevant data access and the null argument violates that contract.
- Statements that only create, store, or pass on a null pointer are supporting evidence, not the primary location, unless they themselves perform the relevant access. Explain the null source and the reachable path to the access.
