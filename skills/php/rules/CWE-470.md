### CWE-470: Use of externally-controlled input to select classes or code

- Trace external input into the selection of a class or method: `new $class(...)`, `$class::method()`, `$object->$method(...)`, or a static call whose target is built from input. Explain whether the input can select a class or method the code did not intend to use, including those an autoloader would load.
- Require the selected name itself to be externally controlled. A class or method name assigned from a visible literal is not externally controlled, and a call whose name is a fixed literal is not a selection defect merely because its receiver is held in a variable, as in `$a::show_one()`. Check for a class-name allowlist, or a mapping from input to a fixed class: mapping input to fixed class literals with `switch` or `match` refutes the candidate, while passing a raw input value into `new` does not.
- Establish a reachable instantiation or call. A class name that appears only in a string comparison, a log message, or a comment is insufficient evidence.
- When a selectable class or its constructor lies outside the supplied file, so that the impact cannot be judged, record it in `limitations`.

#### Finding location

- The primary operation is the instantiation or call that uses the selected class or method name, such as `new $class(...)`, `$object->$method(...)`, or `$class::method()`. Explain the selection point and the name the input controls.
