### CWE-918: Server-side request forgery

- Trace external input into the destination of an outbound request: `curl_init`, `curl_setopt` with `CURLOPT_URL`, `file_get_contents`, `fopen`, `readfile`, `get_headers`, `simplexml_load_file`, `copy`, or a stream context used by one of these calls.
- Report when the attacker can choose or materially alter the scheme, host, port, or path and no effective destination control is visible: no allowlist of hosts or schemes, no fixed base URL whose host cannot be changed, and no redirect restriction.
- A fixed destination host with only an encoded path parameter, and a strict allowlist of destinations, refute the finding.
- A request to a fixed internal service with no externally controlled destination is not a finding.

#### Finding location

- The primary operation is the outbound request call whose destination derives from external input. Explain the controllable destination component and the absent allowlist or fixed host.
