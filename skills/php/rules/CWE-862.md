### CWE-862: Missing authorization

- Identify an operation that acts on a stored object or performs a privileged action using an identifier taken from `$_GET`, `$_POST`, `$_REQUEST`, or `$_COOKIE`.
- Report when the file shows authentication but no authorization decision for that operation: no ownership condition binding the object to the current user, no role or permission check, and no policy call. Session presence (`isset($_SESSION['user_id'])`) proves authentication only, not authorization.
- A visible ownership or permission check that dominates the operation, an operation restricted to the current user's own identifier, and an intentionally public endpoint refute the finding.
- Do not treat a guessed identifier as a separate defect when the same object is already accessible without authorization; report the missing decision once.

#### Finding location

- The primary operation is the data access or privileged action that uses the user-controlled identifier without an authorization check, such as the query, update, delete, download, or approval call. Explain the identifier, the object it selects, and the missing ownership or role condition.
