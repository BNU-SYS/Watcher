# Python CWE candidate index

- CWE-78: An untrusted value supplied as a parameter, request data, configuration, environment variable, filename, or derived from them reaches a shell-parsed command string (`os.system`, `os.popen`, `subprocess.*` with `shell=True`, `asyncio.create_subprocess_shell`, or an explicit `sh -c`/`cmd /c` argument list) through f-string, `%`, `format`, `+`, or `join` interpolation, without effective quoting or allowlisting.
- CWE-95: An untrusted value is evaluated directly as source text, a statement, an expression, or a module name by `eval`, `exec`, `compile` followed by execution, or `__import__`, with no safe parser such as `ast.literal_eval`, `json.loads`, or a numeric conversion in between; object reconstruction from serialized data belongs to `CWE-502` and template or sandbox formatting is outside the registered scope.
- CWE-89: Untrusted input is concatenated into SQL text with an f-string, `%`, `str.format`, `+`, or `.join`, including a dynamic table, column, `ORDER BY`, or `LIMIT` that is not mapped through a strict allowlist, and the resulting statement reaches `cursor.execute`, `executemany`, `pandas.read_sql`, or an equivalent execution entry point without DB-API parameter binding.
- CWE-502: Externally supplied serialized data from a network payload, upload, request body, externally written database or cache value, or parameter reaches a deserializer that can reconstruct Python objects (`pickle`, `cPickle`, `marshal`, `dill`, `shelve`, `jsonpickle`, `pandas.read_pickle`, `torch.load` without `weights_only=True`, `numpy.load(..., allow_pickle=True)`, or `yaml.load`/`full_load`/`unsafe_load` without `SafeLoader`), or reaches a loader constructor that performs dynamic import, attribute resolution, class construction, or state restoration, before any integrity check that constrains the payload to a safe format.
- CWE-295: An outbound TLS connection disables or weakens certificate or hostname verification through `verify=False`, `ssl=False`, `CERT_NONE`, `check_hostname = False`, `ssl._create_unverified_context()`, an unconditionally accepting callback, session or client state inherited by later calls, `PoolManager(cert_reqs="CERT_NONE")`, or a pooled connection whose TLS settings are applied after selection and are absent from the pool key, so a man-in-the-middle can present any certificate.
- CWE-611: Untrusted XML reaches a parser configured to resolve external entities or DTDs (`resolve_entities=True`, `load_dtd=True`, `no_network=False`, a custom `XMLParser` with entity handling, or `defusedxml` with `forbid_entities=False`/`forbid_external=False`), enabling local file disclosure, SSRF, or entity-expansion denial of service; a parser with entity resolution disabled, `defusedxml` defaults, or a fixed literal document is not a finding.
- CWE-22: An untrusted filename, relative path, archive member name, URL-derived path, or static-file request path is joined to a base directory or used directly by `open`, a `Path` read/write, `os.remove`/`rename`, `shutil.copy`/`move`, `send_file`, `send_from_directory`, `extract`/`extractall`, or a static-file resolver including `follow_symlinks=True`, without a resolved-base containment check (`is_relative_to`/`commonpath` applied to both resolved paths), so `..`, an absolute path, or a symlink escapes the base; canonicalization alone and a string `startswith` prefix check do not establish containment.
- CWE-400: A resource grows without a bound under input control — an input-driven loop with no clear termination condition, an unbounded read or accumulation (`read()` without a size, `readlines()` on untrusted data), an unbounded retry, recursion over untrusted depth, or decompression of an untrusted archive — with no size or attempt limit enforced before the operation, causing memory growth, CPU exhaustion, file-descriptor exhaustion, or a hang; regex backtracking is outside the registered scope.
- CWE-190: An input-derived value crosses a fixed-width integer boundary (`ctypes.c_int`/`c_short`/`c_long`, `struct.pack` with `b`/`B`/`h`/`H`/`i`/`I`/`l`/`L`, an `array` typecode, a small NumPy integer dtype, or a C extension boundary) and can exceed the representable range without a preceding range check, producing silent wraparound, truncation, or a negative value used for sizing, indexing, or a security decision; native Python `int` is arbitrary precision and a value already range-checked is not a finding.
- CWE-798: A non-placeholder credential literal — a password, API key, access token, private key, or a connection string that embeds a password — is embedded in code that authenticates, including as a default argument or class attribute, instead of being read from the environment or a secret manager; a variable name alone, a secret hash, or a value used only for a non-authentication purpose is not a finding.
