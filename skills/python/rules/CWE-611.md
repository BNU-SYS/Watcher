### CWE-611: XML external entity (XXE)

- Identify XML parsing of untrusted input: `xml.etree.ElementTree.parse/fromstring`, `xml.dom.minidom.parseString`, `xml.sax`, `lxml.etree.parse/fromstring`, `xmltodict.parse`, or `defusedxml` used with entities enabled.
- Establish that the parser is configured to resolve external entities or DTDs: `resolve_entities=True`, `load_dtd=True`, `no_network=False`, a custom `XMLParser` with entity handling, or `defusedxml` called with `forbid_entities=False`/`forbid_external=False`.
- Establish the consequence: local file disclosure, SSRF, or entity-expansion denial of service.
- Do not report `defusedxml` with its defaults, a parser with entity resolution explicitly disabled, or parsing of a fixed literal defined in the same file.
- The standard library `xml.etree.ElementTree` in current CPython does not expand external entities by default; do not report it unless the source visibly overrides that behavior or the input path is an `lxml` parser configured to resolve entities.

#### Example

```python
from lxml import etree

def parse(document):
    parser = etree.XMLParser(resolve_entities=True)   # external entities resolved
    return etree.fromstring(document, parser)
```

#### Finding location

- The primary operation is the parser construction or the parse call that enables entity resolution. Cite the untrusted input in `explanation`.
