### CWE-190: Integer overflow or wraparound

- Identify a fixed-width integer boundary: `ctypes.c_int`/`c_short`/`c_long`, `struct.pack` with `b`/`B`/`h`/`H`/`i`/`I`/`l`/`L`, `array` typecodes, `numpy` integer dtypes (`int8`, `int16`, `int32`, `uint8`, ...), or a C extension boundary.
- Establish that the value crossing the boundary is input-derived and can exceed the representable range, and that no range check precedes the conversion.
- Establish the consequence: silent wraparound, truncation, or a negative value used for sizing, indexing, or a security decision.
- Do not report Python `int`, which is arbitrary precision, a value already range-checked, a constant within range, or NumPy behavior that raises on overflow in the configured mode without a wrong result.
- `numpy` integer arithmetic wraps silently by default; a value converted into a small dtype without a bound check is a finding.

#### Example

```python
import ctypes

def to_int(value):
    return ctypes.c_int(value).value   # value > 2**31-1 wraps
```

#### Finding location

- The primary operation is the conversion or fixed-width arithmetic that can overflow. Cite the input origin and the missing range check in `explanation`.
