### CWE-400: Uncontrolled resource consumption

- Identify an unbounded resource: an input-driven loop, an unbounded read/accumulation, an unbounded retry, unbounded recursion, or decompression of an untrusted archive without a size limit.
- Establish the growth driver: `while True` with no break on a condition derived from input, a counter that moves away from its termination condition, `stream.read()` with no size, `readlines()` on an untrusted socket, retry loops with no attempt limit, or recursion over untrusted depth.
- Establish the observable consequence: memory growth, CPU exhaustion, file-descriptor exhaustion, or a hang that makes the service unavailable.
- Do not report a loop with a clear termination condition, a bounded read (`read(n)`), a retry with a fixed attempt limit, a recursion over a fixed structure, or a size limit enforced before the operation.
- Distinguish from `CWE-1333`: this rule is about loops, reads, retries, and decompression, not regex backtracking.

#### Example

```python
def drain(stream):
    data = b""
    while True:                 # no end-of-stream check
        data += stream.read(1024)
    return data
```

#### Finding location

- The primary operation is the loop header, unbounded read, retry, or recursive call that drives consumption. Cite the input that keeps it growing in `explanation`.
